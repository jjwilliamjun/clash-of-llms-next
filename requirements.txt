# Runtime dependencies for the Flask backend. Requires Python 3.10 or later.
#
# Only direct dependencies are listed. The previous file pinned pylint's transitive
# tree (astroid, dill, isort, mccabe, wrapt, ...) alongside the runtime, which made it
# impossible to tell what the application actually needed from what a linter dragged in.
#
# Lower bounds rather than exact pins: this is a research tool that people clone and
# run, and exact pins from one machine's freeze are what made the old file unusable on
# any current Python.
#
# PyTorch and TensorFlow are NOT here. They are only needed to serve an uploaded custom
# model, they weigh several gigabytes, and they were the reason this project could not
# move past the Python version they happened to support. See requirements-custom-model.txt.

Flask>=3.1,<4
Flask-Cors>=6.0,<7
Werkzeug>=3.1,<4

# Simulation
networkx>=3.4,<4
